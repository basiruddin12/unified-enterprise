UNIFIED ENTERPRISE WEBSITE

Files:
- index.html: the complete responsive website.

Before publishing:
1. Your supplied address, phone/WhatsApp number and email have already been added. Review them in index.html before publishing.
2. Check that every listed service is genuinely available to you.
3. Keep the authorisation notice. Do not claim to provide Aadhaar enrolment/update or banking transactions unless you are authorised to do so.

Free publishing using GitHub Pages:
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository named unified-enterprise
3. Upload index.html to the repository's main/root folder.
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. Your free site address will look like:
   https://YOUR-GITHUB-USERNAME.github.io/unified-enterprise/

Google visibility:
- After the site is live, add its published URL in Google Search Console.
- For a github.io site, use the URL-prefix property and verify using the method Google offers.
- Submit sitemap only if one is created; for this simple one-page site, request indexing of the homepage.
- Indexing is not guaranteed or immediate.

This package does not publish the website automatically. You will need to create the GitHub account/repository and upload the file.
